# Frontend Standardization Guide: MUI Theme **Goal:** To ensure a consistent, stable, and visually coherent user interface across the SoundsGood application by standardizing on the Material UI (MUI)-inspired theme defined in `base.html`. This approach avoids conflicts caused by mixing CSS frameworks (like Bootstrap and MUI) and provides a clear path for future frontend development. **Core Principle:** **All new and refactored frontend templates MUST extend `base.html` and exclusively use the styling conventions outlined below. Bootstrap classes and components are strictly forbidden.** **1.
