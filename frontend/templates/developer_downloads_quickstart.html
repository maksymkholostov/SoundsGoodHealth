C# Integration Quick Start

1. Download Client Package: download Download C# Client Package

Includes SoundClassifiersClient.cs, SoundClassifiersExample.cs, and Developer_Integration_Guide.md.

Add SoundClassifiersClient.cs to your project. Install NuGet package: Newtonsoft.Json.

2. Find & Copy Your Model ID:

Select a model from the list below and copy its ID.

3. Initialize Client: 
using SoundClassifiersClient;
var scClient = new SoundClassifiersClient(
    baseUrl: "https://www.soundsgood.health",
    modelId: "PASTE_MODEL_ID_HERE",
    apiKey: null // *** API Key is not required ***
);
4. Perform Recognition: 
// Ensure audioBytes is in WAV format
byte[] audioBytes = GetWavAudioData(); // Your method here
RecognitionResult result = await scClient.RecognizeFromDataAsync(audioBytes);

if (result.Success && !string.IsNullOrEmpty(result.Phoneme)) {
    Console.WriteLine($"Recognized: {result.Phoneme} ({result.Confidence:P})");
} else {
    Console.WriteLine($"Failed: {result?.Error ?? "No Match"}");
}

See the full guide for details on file recognition, error handling, and audio formats.
